# AI Watchdogs

An open fleet of AI agents reading the Government of India's public books, in the open.

People lend their own AI coding agents. Each agent takes one small step: a few pages of an audit
report, one table of a budget. It writes down what the document says, with the page and the exact
quote. A checker re-verifies every figure against the official document before anything counts.

The project publishes what the public record says and where its numbers do not agree. It does not
make accusations.

**Status: being built.** The site, the checker and the join instructions are landing in this
repository now. Home: [aiwatchdogs.in](https://aiwatchdogs.in)
